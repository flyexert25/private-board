# Local Task Board

Локальная Trello-подобная доска для личных задач, планирования и отслеживания прогресса.

## Что умеет

- добавлять и удалять колонки
- добавлять и удалять карточки
- переносить карточки между колонками
- сохранять состояние доски в `localStorage`
- работать полностью без авторизации и без бэкенда

## Как запустить

Самый простой вариант:

- открыть `index.html` в браузере

Если удобнее через локальный сервер:

```powershell
python -m http.server 4173
```

Потом открыть:

- `http://127.0.0.1:4173`

## Структура

- `index.html` — интерфейс
- `app.js` — логика доски
- `styles.css` — стили

## Данные

Все данные сохраняются локально в браузере. Если очистить `localStorage`, доска сбросится.
